## Measurement rules

- Each commit is measured against its first parent. The root commit is compared with the empty Git tree. This captures merge resolution once while counting branch commits as their own commits; there are no merges through the fixed endpoint.
- Diffs use Git numstat with rename detection disabled. `Files` counts changed paths, so a rename is represented as a deleted path plus an added path.
- `Raw + / − / total` gives added lines, deleted lines, and their sum. Binary files have no line count in numstat; they still count as files and appear in `Binary files`. No binary changes occur through the fixed endpoint.
- `Authored + / − / total` uses the same line counts after excluding lockfiles, confirmed generated output, and only the static fixture data listed below. Totals are additions plus deletions, not net growth. Repeated edits are counted in every commit where they occur.
- Excluded paths are narrowly scoped to files observed in the measured history:
  - **Lockfiles:** `pnpm-lock.yaml`, `package-lock.json`, `yarn.lock`, `bun.lock`, `bun.lockb`, `npm-shrinkwrap.json`, and files ending in `.lock`.
  - **Generated output:** only `apps/web/src/routeTree.gen.ts`. This is the sole generated/gen path match through the fixed endpoint; its header identifies it as generated by TanStack Router. No ordinary authored module matched the generated-path audit.
  - **Fixture data:** `apps/demo-target/src/fixtures/**`; `apps/validator/test/fixtures/node-regression/package.json`; and `apps/validator/test/fixtures/node-regression/src/feature.js`. The package lock is already excluded by the lockfile rule.
- Other code remains authored, including the demo target README, package manifest, server (`src/index.ts`), entrypoint (`src/main.ts`), server test, TypeScript configs, and the node-regression harness `test/run.js`.
