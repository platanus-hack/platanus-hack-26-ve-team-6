This is a foundation, not a completed security product.

Production MFA and trusted verifiers, provider integrations, model access, cloud deployment, scanner services, customer VM isolation, production TLS, restore proof, capacity proof, and cost evidence remain release gates. Proposed limits are not measured guarantees.
