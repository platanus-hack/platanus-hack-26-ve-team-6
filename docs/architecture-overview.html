Fixed demo and assessment limits

Public API limits

Requests cannot choose a tenant, application, target URL, or path. Backend admission is capped at three unfinished and 100 lifetime jobs. Per web process, the API caps new idempotency keys at 10 per rolling minute and POSTs at 30 per 60-second window.

No general scanner or exploit

No source execution, package installation, customer tests, exploit attempt, general SAST, or broad web scan. A vulnerable advisory match is not proof of installed code or exploitation. Missing coverage is not a secure result.

Severity does not grant authority.

The demo performs no changes. Exact approval, bounded preauthorized automation, automatic response, and cross-provider recovery are separate later release gates.

Runtime and deployment evidence

Local controlled demo

Node 24, pnpm 11, and Docker. Built web/coordinator processes use loopback ports 3000/3003; the inline HTTP target uses 4100. State and logs are recorded under .local/demo.

AWS primary target

Pulumi defines two EC2 instances and private S3 artifact storage. Policy tests use mocks. No AWS deployment or live AWS check has been made.

Portable core

Open contracts and replaceable adapters keep GitHub, model APIs, OIDC vendors, and paid services optional. Auth.js supports generic HTTPS OIDC or GitHub sign-in; live OAuth is unproven.

This is a controlled assessment demonstration.

Monitoring and alerts, general scanners, customer-code execution, production identity and approvals, provider writes, production TLS, restore evidence, measured capacity, and operating-cost evidence remain gates. Reference limits and mock tests are not production guarantees.
